# 智能运营决策分析平台

面向用户行为序列分析、RFM分层、流失预警、智能推荐、归因建模、活动效果评估与实时运营决策的数据分析工程平台。

这是一个前后端分离的管理平台：前端 React + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 推荐场景增量命中重算（recoincr）

解决存量重算链路在推荐场景/冷启动策略变化时重算全部已发布策略、导致无关策略评分与
复用次数被刷新的问题。只按场景边界做局部收敛：

1. **增量范围来源**：推荐场景变化记录（`/api/recoincr/changes`），提交批次时只取指定
   变化单覆盖的场景，识别引用该场景的已发布策略库候选，其余策略完全不触碰。
2. **受影响与已完成分别保留**：批次明细按场景逐条登记，受影响场景为「已完成-局部重算」，
   未受影响场景为「已保留-沿用原结果」；命中明细数据集只写入状态确定（已完成/已保留）的记录。
3. **重试只补未完成**：`/retry` 仅补写「待处理」场景，已完成场景与保留结果不允许被覆盖。
4. **一次有效写入**：批次按幂等键去重，命中明细按业务键（批次号+推荐场景+策略编号）去重，
   并发提交同一业务记录只落一次库（服务层有写锁兜底）。
5. **策略库局部应用**：`/apply` 只更新引用变化场景的策略评分与复用次数，未变化场景原样保留；
   新旧评估范围同时覆盖同一候选时，按数据版本仲裁，同一场景只保留一套可解释的当前推荐。
6. **版本回查**：每次应用生成数据版本快照（策略库快照+命中明细快照），支持按版本回查与回滚。
7. **漂移核对**：`/batches/{批次号}/drift` 对比受影响/未受影响场景的评分、推荐结果与复用次数，
   确认评审中配置不会替换上线场景、未变化部分零漂移。RECO-0002 为主核对样例。

核验脚本（后端需先启动）：

```bash
cd backend
.venv/bin/python -I tests/test_recoincr_service.py   # 服务层单测：断点补写、并发幂等等
.venv/bin/python -I tests/verify_recoincr.py         # HTTP 端到端核验（RECO-0002 主样例）
```
